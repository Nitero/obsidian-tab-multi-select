# Tab Multi Select

Select and control multiple tabs with intuitive inputs, inspired by browsers like Firefox.

![ScreenRecording2026-01-26211838-ezgif com-video-to-gif-converter](https://github.com/user-attachments/assets/10c378c0-1c66-4367-b77b-eca79115f0d0)

## Usage

- Shift click - Select tabs in a range
- Control click - Toggle selection of individual tabs
- Middle click - Close selected tabs
- Right click - Context menu for selected tabs
- Drag selected tabs - Move to another tab group or window
- Undo close tab hotkey - Bring back closed tabs selections
